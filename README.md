# 汇报工作台

源码仓库：[camellia-sad/PresentationStudio](https://github.com/camellia-sad/PresentationStudio)。当前版本为 1.11.0；仓库包含编辑器源码、桌面封装、测试、示例项目与使用教程。Electron 运行时、个人项目、组件库、测试缓存和本机部署备份不上传。

获取源码后，在项目根目录执行 `python build.py` 可生成可离线打开的 `汇报工作台.html`。Windows 桌面包使用 `python desktop/build_desktop.py` 构建，首次会下载并校验 Electron 运行时。数据回归可执行 `node --test *.test.cjs desktop/store.test.cjs`；浏览器回归使用 Playwright，详见下方验证说明与 AGENTS.md。

用户入门与全功能操作请打开 [完整使用教程（离线网页版）](docs/manual/汇报工作台完整使用教程.html)，或阅读 [文字版](docs/manual/用户使用教程.md)。配套 [练习项目](docs/manual/练习项目.studio.json) 可直接导入；教程包含 20 章、真实界面截图、快捷键与常见问题。

正式开发目录：`D:/codex_workspace/presentation-studio`。当前桌面安装：`D:/PresentationStudio`。原毕业设计目录保留为旧源码，不再写回。`python build.py` 以仓库内公共示例生成离线编辑页；不依赖外部文献。

## 1.10.0 编辑体验

- 画布右键仅粘贴，选区中心落在右键处；格式、尺寸、聚焦和重叠对象选择在右栏。
- 我的组件 → 管理 → 编辑打开独立小画布，可拖动、缩放、多选、修改文字/颜色/字号、添加文字/形状/图标、复制/删除/调整层序与撤销重做。保存只更新模板，返回或Esc取消，已插入副本保持不变。小画布暂不编排步骤/动效或新建连线，图片可移动缩放。
- 跳转步骤同时展示编号与完整名称，单击选择，输入编号后可单独聚焦。
- 默认浅色专业编辑器：白色面板、浅灰工作区、蓝色操作与选中反馈。基础工具采用浅蓝紫色块和统一SVG图标，个人组件以暖杏底板、真实缩略图与名称显示，列表限高滚动。
- 顶部文件名与保存状态相邻，文件操作、撤销重做、导出和演示分组；底部集中缩放、平移、适应画布、聚焦及上一视野，实际画布尺寸调整仍在右侧。
- 右侧按画布、文字、图片、多选或步骤显示属性；组合内容列表可进入内部对象编辑，多选差异显示“混合值”。轻分隔与留白替代嵌套卡片。
- 步骤页显示编号、真实内容缩略图和当前状态；编辑组件时不显示步骤缩略图。空画布提供添加标题/图片的入口。
- 顶部月亮按钮切换浅色/深色界面，主题只保存在本机，不修改汇报背景、网格、文字或导出数据。双侧栏仍支持限定范围拖动。

## Windows 桌面版

解压 `release/汇报工作台-Windows-x64.zip`，双击文件夹内的 `汇报工作台.exe`。这是免安装的 Windows x64 程序，运行时不需要 Python、Node 或网络；请保留完整文件夹，不要单独搬走 exe。桌面快捷方式指向此程序。

桌面版与 HTML 版共用编辑器和项目格式。本机项目实际保存在 `D:/PresentationStudio/data/projects`，原 `%APPDATA%\PresentationStudio` 是兼容目录链接；可从“项目 → 项目文件夹”打开。每个项目为独立记录文件，采用临时文件写入、刷新后替换，并保留上一版 `.bak`；正常关闭窗口会先等待保存完成。更新程序不会清空这个目录。

浏览器的本机草稿不会自动搬进桌面版：先在原 HTML 中导出最新的项目 JSON 或 HTML，再在桌面版点击“导入”。如果只导入最初下载的 HTML，得到的是该文件内嵌的版本，不是浏览器中尚未导出的修改。

“项目”列表支持删除，删除后进入项目回收站，刷新或重启后仍可恢复。删除当前项目时自动切换到其他项目；没有其他项目时打开空白项目。删除不会影响已经导出的文件。

后续功能仅更新桌面 App，旧独立 HTML 入口保持原版本。桌面版导出的 HTML 随当前编辑器生成，继续支持离线演示与项目数据导入。

1.8.0：项目管理支持关闭/Esc退出，回收站、导入、新建和删除确认统一返回项目管理。项目回收站可经二次确认永久清空，只删除已回收项目。顶部深色品牌卡片的图标与文字均返回主页。画布设置移除叉号和重复导入。

个人组件快捷列表限高滚动；管理页采用卡片矩阵，左侧独立预览，选中后插入。复制/剪切后单击画布，再粘贴，选区中心落在点击位置。自由线支持拖入组件，拆分后跟随组件；鼠标或组件中心靠近线均可命中，Alt临时跳过。

1.7.0：拖动左右边栏靠近画布的分隔线调整宽度。左侧190–360px、右侧260–420px，默认220/300px；窄窗口会自动收窄。双击恢复默认，Tab聚焦分隔线后左右方向键微调，Shift加速，Home恢复，Esc取消正在拖动。宽度只保存在当前设备，不影响项目与撤销。

属性区优先显示内容和排版；点击分组标题展开外观、动效、交互、图层操作等设置，切换对象保留本次会话的展开状态。“出现与退场”与“动效”分开。网格/对象吸附、拖入连线和导图快捷键默认开启且不显示开关；按住Alt临时跳过。Tab/Enter仅在画布焦点且单选时创建分支，输入框Tab仍导航。

1.2.0：图层按“出现步骤 → 组合/组件/连线”组织，步骤可展开/折叠，跨步骤组合仍保留原组合关系。眼睛现在直接控制编辑画布，可以隐藏整步、组合、单项或选中的多个组件；恢复全部可一键找回。图层会标出隐藏项和部分可见的步骤。

想在上层遮盖下编辑内容：选上层组件 → Ctrl+H 隐藏 → 编辑下层 → Ctrl+Shift+H 恢复全部；也可在右侧“图层操作”选择“仅看所选”。图层的“模拟本步画面”会按出现/退场步骤显示累计内容，便于检查上层退场后的布局。临时隐藏与模拟支持撤销/重做，重开本机项目保留；演示与导出不受影响。正式退场仍在右侧设置“退场步骤”，旧的永久隐藏改称“正式演示中始终隐藏”。

- 选中曲线或直线后，拖动线条中间圆点调整弯曲；直线会转为曲线，两端位置保持。右侧“恢复默认弯曲”可清除调整。编辑时箭身、箭头和标注始终使用设置的颜色。
- 右侧“出现与退场”提供“退场步骤（从该步起隐藏）”，支持单个、组合和多选组件及连线。例如 A/B 从第 1 步出现，B 从第 2 步退场，C 从第 2 步出现，即第 1 步 A+B，第 2 步 A+C。回到前一步会恢复 B，连接 B 的箭头同步隐藏；“全部展开”显示未设为正式演示隐藏的对象；编辑画布另受临时隐藏和步骤模拟控制。
- 复制、复制粘贴和剪切粘贴保留当前视角与缩放，只选中新副本。

- 从左侧组件库添加文字、标题、形状、图标、图片、表格、交互按钮或组合卡片。
- 单击卡片内的任意组件，先选择整个组合；双击文字区域才单独选中文字组件；选中文字组件后，再单击即可直接编辑，光标落在点击位置。拖动仍移动当前选中的对象，不会进入文字编辑。
- 单独选中文字时，编辑框四周额外留出 8 像素，方便看清边缘光标、点击和拖拽。留白随缩放保持可见，不改变文字位置、换行或保存的组件尺寸；取消选择及演示时恢复原有外观。
- 右侧可修改文字、位置、大小、字体、颜色、边框、透明度、动画和点击行为。文字输入即时同步到画布，连续输入合并为一次撤销。F2 或右侧编辑按钮也可进入画布文字编辑；Ctrl+Enter 完成，Esc 取消这次画布内文字修改。
- 画布上的 Ctrl+A 全选可见组件；在输入框中仍全选当前文字。点击画布或在右侧按 Esc 即返回对象选择。底部“全选组件”按钮和 Ctrl+Shift+A 可直接从输入框切换为全选可见组件。
- 卡片中的说明、标签和图注都是独立文字对象。Alt 单击可直接选中组合内部组件。Ctrl / Shift 单击多选，Shift 拖动空白处框选。
- 右侧提供组件居左、水平居中、居右按钮。单个组件及完整组合相对画布对齐，整组移动保留内部布局；多个独立组件相对选中范围对齐。文字另有居左、居中、居右按钮。
- 单独选中文字后，右上方显示快捷工具条，可直接修改字体、字号、加粗、颜色、文字对齐和组件位置对齐。字号旁的 B 按钮切换整段文字的加粗与常规字重，并与右侧字重设置同步。
- 图标按框的宽度和高度分别拉伸；拖动宽扁或高窄的框时，图标随框变形。Shift 拖角仍可保持比例。
- 拖动或缩放组件越过有色画布的四周时，画布实时向相应方向扩展并留出余量。组件移动与画布扩展属于同一次撤销，Esc 可取消本次拖动。
- 左侧组件栏顶部“插入空间”：选择向下或向右，在需要留空的位置拖动。橙色轮廓预览受影响的组件；跨过分界线的组件或组合整体移到空隙之后，连线跟随，已记录的下游步骤镜头同步移动。含锁定对象时提示先解锁，松手完成，Esc 取消。
- 把单个组件或完整组合拖到箭头上，出现绿色高亮和“松开插入”提示后松手，A → B 自动变为 A → 该组件 → B。组合以背景形状为连接对象；连线样式继承，原标注保留在前半段。没有高亮时只移动；按住 Alt 可跳过连线插入。整次移动与插线可一次撤销。
- 也可先选中箭头，再在右侧点击“在箭头中间插入组件”，新建文字卡片、形状、图标、表格或按钮，或接入已有组件。周围空间不足时，先使用“插入空间”。
- 画布随内容自动扩展；“适应画布”查看整体，右侧“画布包住全部内容”可自动留白。不开放画布边界、宽高或组件位置尺寸的数值输入；组件继续用拖动和边缘手柄调整。
- 选中组件后，拖左右边只改宽度，拖上下边只改高度，拖四角调整宽高。整个边缘都可拖拽，外侧紫色圆点专用于连线；Shift 拖角保持比例。
- 演示时背景色自动铺满整个窗口，标题靠近画布顶边也不会出现上下不同的底色。
- 左侧“连线”进入画线模式，在空白处、组件或图片上拖拽即可画自由线条，显示在图片上方。Shift 限制水平、竖直或 45°；Esc 取消。画完后可拖整条线移动，拖两端圆点调整，右侧修改颜色、粗细、箭头和标注；支持撤销、复制粘贴及保存导出。依次单击两个组件仍创建随组件移动的连接。
- 拖动紫色连接点创建连线。连线跟随对象移动，支持曲线、折线、箭头、标签和描线动画。
- 直接拖动空白处可上下、左右平移视野。底部“拖动画布”开启手形模式后，在组件上拖动也只平移；再次点击或按 Esc 返回选择。空格拖动、中键拖动仍可临时平移。
- 底部“左右平移”横拉条和两端箭头可横向导航；Shift 加滚轮也可横移，Ctrl 加滚轮缩放。视角与组件坐标分别保存，平移不会改变组件位置。
- 画布获得焦点且选中单个组件时，Tab 添加子节点，Enter 添加兄弟节点；按住Alt跳过，F2或Alt+Enter编辑文字。“整理子树”自动排列通过父子关系建立的分支。
- Ctrl+G 组合，Ctrl+Shift+G 取消组合，Ctrl+D 复制，Ctrl+Z 撤销。

## 演示与保存

“步骤”面板管理播放次序、停留时长、备注和镜头。选中对象后可指定出现步骤、动效、时长和延迟。步骤重排后，对象继续关联原步骤。

为新步骤加入已有组件：选中一个或多个组件，在右侧“出现与退场 → 出现步骤”选择目标步骤。为新步骤添加新组件：先在“步骤”栏选中目标步骤，再切到“组件”栏添加，自动归入当前步骤。镜头只控制视角；出现步骤控制首次出现的时间，演示中会保留此前出现的组件。

通过“导出”保存项目 JSON、演示版 HTML、全部展开 HTML 或可编辑 HTML。HTML 内可随时切换逐步演示与全部展开，并返回编辑；图片和项目数据全部内嵌。全部展开显示所有未设置“正式演示中始终隐藏”的组件，支持拖动平移、Ctrl 加滚轮缩放、点击原图放大。

“导入”支持项目 JSON，以及旧版或新版工作台导出的 HTML。HTML 导入只提取 `seed-project` JSON 数据，不执行导入文件的脚本，不加载外部资源。每次导入创建独立项目，不覆盖同名项目。普通网页或早期没有该项目数据段的演示网页无法还原成工作台组件，界面会明确提示。

自动保存存入当前浏览器，不会覆盖硬盘上原来的 HTML。需要把修改带到另一台电脑，或长期保留版本时，请重新导出。建议使用桌面版 Edge 或 Chrome。

论文原图是图片对象，可替换、缩放、旋转、裁切或叠加其他对象。若要逐字改动图内内容，可以用文字、形状和连线组件重绘。

## 项目结构

`projects/Guess-Sketch.studio.json` 是完整示例，`schemaVersion` 当前为 1。

- `canvas` 保存画布起点 `x/y`、尺寸、背景、网格和吸附设置。旧项目未记录起点时按 `(0,0)` 读取；向上或向左扩展可以产生负坐标。
- `nodes` 保存所有对象。每个对象具有稳定 `id`、类型、坐标、尺寸、旋转、样式、出现步骤和点击行为。文字存入 `text`，表格存入 `cells`，图片通过 `assetId` 引用素材。
- `edges` 使用对象 ID 关联起点和终点，记录锚点、路径、颜色、箭头、文字标签和动画。
- `groups` 保存组合名称与成员 ID。成员使用画布绝对坐标，可以单独编辑。
- `steps` 保存稳定 ID、名称、时长、备注及可选镜头。对象通过 `stepId` 关联步骤。
- `assets` 保存内嵌图片、名称与原始宽高。多个图片对象可以引用同一素材。

项目数据通过导入/导出交换，界面不提供原始 JSON 编辑器。导入时校验组件和引用关系。

```powershell

```

## 源码与构建

- `core.js` 定义数据结构、校验及复制、删除、组合等文档操作。
- `app.js` 实现画布交互、属性编辑、自动保存、演示和导出。
- `studio.css` 定义编辑器和演示界面的外观。
- `index.template.html` 定义界面骨架。
- `build.py` 生成独立 HTML 与示例项目。
- `desktop/` 提供 Electron 桌面入口、隔离的文件接口、项目文件存储及 Windows 打包脚本。

## 图层多选、导航和汇合插入

- 图层行右侧的眼睛控制编辑画布显示或隐藏，不改变演示；锁控制位置与尺寸锁定。悬停可查看当前状态。
- 左侧图层栏开启“多选”后，点击行或勾选框追加／取消选择。也可不打开多选模式，直接 Shift / Ctrl + 点击。组合支持整体选择和部分勾选；多选不改变镜头或跳动列表。
- 多选文字组件后，右侧支持批量修改字体、字号、字重、颜色与文字对齐；同样可以移动、对齐和组合。输入即时反映到画布。
- 点击画布组件时，已打开的图层或步骤栏会自动定位对应条目。多选跨步骤时显示各步骤包含的选中数量；组件栏保持原入口，避免打断新增组件。
- 多条箭头指向同一组件的同一接口时，拖动组件到共同终点附近，会同时高亮相关入线并提示数量。松手后保留全部入线的样式和标注，增加一条通向原终点的出线，并留出间距；整组组件也可以插入。Alt 暂时跳过，Ctrl+Z 一次撤销。
- 也可选择一条入线，在右侧点击“在汇合处插入组件”，新建或接入已有组件。普通单线入口仍可使用，并可在弹窗中切换是否处理全部入线。只是几何交叉、或连接不同接口的线不自动合并。
- 新出线继承第一条入线的样式，标注留空；入线保留原出现步骤，同时等待新组件出现，共用出线最早随一条原分支和两端组件出现。不会复制出多条重叠出线。

## 用组件创建步骤、插入和拖拽排序

- 选中一个或多个组件，点击右侧顶部或左侧“步骤”栏的“用所选 N 个组件创建步骤”。新步骤插在当前步骤之后，所选组件移入新步骤，原步骤和未选组件保留；组件位置不变，不复制组件。内部连线同步归入新步骤，关联的外部连线等待两端组件出现。
- 每张步骤卡片下方都有“在此下方插入步骤”，点击即可插入空白步骤；列表末尾仍支持追加。创建后自动定位新步骤，可在右侧修改名称、备注和镜头。
- 拖动步骤卡片的标题或空白区域，到另一张卡片上半部／下半部，紫色插入线分别表示插到前面／后面。拖到列表边缘会滚动；Esc 或移出列表松手取消。步骤携带组件归属、备注、时长和镜头，既有步骤跳转引用保持有效。
- 创建、插入及每次拖拽排序均可一次撤销；原“前移／后移”按钮保留。方向键移动仍为每次 1px，Shift + 方向键为 10px。

桌面打包使用固定版本 Electron 45.3.2，下载官方运行时并验证 SHA-256，无需全局 npm。打包脚本需要 Python 和 Pillow；首次构建需联网，缓存后可离线重复构建。Electron 许可证和 Chromium 许可证随程序保留。当前交付为未签名的本地构建，未制作安装器或自动更新服务。

桌面窗口遵循 [Electron 上下文隔离](https://www.electronjs.org/docs/latest/tutorial/context-isolation/) 与[安全建议](https://www.electronjs.org/docs/latest/tutorial/security)：编辑页启用沙箱、关闭 Node 集成，预加载只暴露限定文件操作；IPC 验证来源窗口，项目文件标识不允许路径字符，HTML 使用脚本哈希 CSP。

编辑器适合桌面浏览器。较窄窗口中，选中对象后属性面板会从右侧覆盖展开，点属性标题旁的关闭按钮返回画布。

## 1.1.0 操作更新（2026-11-15）

- 顶部“搜索”或 Ctrl+K / Ctrl+F：搜索对象名称、文字、表格内容、步骤和操作；方向键浏览，Enter 定位。项目列表也支持名称搜索。
- 图层支持搜索、类型筛选和组合折叠。单击只选择，双击聚焦；“上一视野”或 Alt+左方向返回搜索前的视野。
- 画布 Ctrl / Shift 单击均支持多选；右键仅提供原位粘贴；重叠选择、格式与尺寸操作位于右侧属性栏。小于 4 屏幕像素的移动不会当成拖动。位置拖动有边缘/中心参考线，Alt 暂停网格和对象吸附。
- 拖入连线和导图快捷键默认开启，按住Alt临时跳过；开关不向用户展示。
- Ctrl+S 即时保存到本机；Ctrl+Shift+S 导出 JSON。F5 从头、Shift+F5 从当前步骤演示，输入框焦点下也可使用。
- Ctrl+Shift+C / V 复制/粘贴整组件格式，Ctrl+B 切换选中文字组件加粗；搜索或右侧“格式与视野”可统一宽高。
- Ctrl+C / X / V 使用系统剪贴板传递组件；直接粘贴外部文字和截图图片。文字编辑时保留原生文本剪贴板操作。
- 左侧“动效编排”或右侧“编排本步动效”：可上移/下移排序，选择本步开始、与上一项同时、上一项之后；支持一键依次/同时播放。界面以秒编辑，数据仍以毫秒保存。
- 增加从左/右滑入、从上落入、缩小落定；演示支持暂停/继续动效、重播本步。自动播放会等待本步最长动画结束。
- 复制组合按钮自动指向副本；删除步骤会重定向跳转，解组/删除对象会清理失效组合交互；跨项目粘贴避免素材 ID 覆盖。

本版仍使用单个进入效果加步骤退场；未实现多轨时间轴、同一对象多效果轨道、运动路径或富文本局部格式。大项目渲染性能另需专项优化，不能据本轮功能测试推断性能上限。
